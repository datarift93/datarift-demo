# datarift-demo

Demo portfolio BI: analityka sprzedaży fikcyjnej polskiej sieci handlowej **„Wisła”** (ok. 25 sklepów stacjonarnych + sklep internetowy, dane z 2 lat). Pokazuje cały proces: generowanie danych w Pythonie, pipeline importu z walidacją, model danych w Supabase (Postgres + RLS) oraz dashboardy w Next.js: KPI, produkty (ABC), klienci (RFM, kohorty), plan vs wykonanie i wykrywanie anomalii.

**Stack:** Next.js (TypeScript), Supabase, Vercel, Python, GitHub Actions.
